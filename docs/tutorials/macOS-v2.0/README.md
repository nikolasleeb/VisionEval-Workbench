# Mac 2.0 Guides and Walkthroughs

Illustrated guides for VisionEval Workbench 2.0 on Apple Silicon macOS. Read the PDF or download the editable Word copy.

| Guide | What it covers | PDF | Editable Word |
|---|---|---|---|
| Installation and Setup | Install Docker and Workbench, verify the runtime, and install asset packages. | [Read/download PDF](Mac-2.0-Installation-and-Setup.pdf) | [Download Word](Mac-2.0-Installation-and-Setup.docx) |
| Project and Scenario | Develop a region, edit and review scenarios, run models, and compare results. | [Read/download PDF](Mac-2.0-Project-and-Scenario-Walkthrough.pdf) | [Download Word](Mac-2.0-Project-and-Scenario-Walkthrough.docx) |
| Hypercube | Build a fuel-cost and tax matrix, run cases, find changes, inspect maps, and export. | [Read/download PDF](Mac-2.0-Hypercube-Walkthrough.pdf) | [Download Word](Mac-2.0-Hypercube-Walkthrough.docx) |
| Workspaces and Resources | Set Docker resources and concurrency, move to an SSD, and reopen a workspace. | [Read/download PDF](Mac-2.0-Workspaces-and-Resources.pdf) | [Download Word](Mac-2.0-Workspaces-and-Resources.docx) |

Watch the accompanying [Mac videos](https://sites.google.com/view/ve-workbench/documentation/mac-resources). The guides follow the videos' examples and explain the current application behavior.

Earlier Apple Silicon installation and scenario guides are preserved in the [legacy guide index](../archive/README.md).
