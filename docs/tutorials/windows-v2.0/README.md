# Windows 2.0 Guides and Walkthroughs

Illustrated guides follow the Windows tutorials and use native Windows execution with one active model job at a time. Read the PDF or download its editable Word source.

| Guide | What it covers | PDF | Editable Word |
|---|---|---|---|
| Installation and Setup | Install Workbench, select a workspace, reuse or install the native RC7 runtime, verify it, and install asset packages. | [Read/download PDF](Windows-2.0-Installation-and-Setup.pdf) | [Download Word](Windows-2.0-Installation-and-Setup.docx) |
| Project and Scenario | Build regional assets, create and review scenarios, queue runs, compare results, inspect maps, and export. | [Read/download PDF](Windows-2.0-Project-and-Scenario-Walkthrough.pdf) | [Download Word](Windows-2.0-Project-and-Scenario-Walkthrough.docx) |
| Hypercube | Build the nine-case fuel-cost and tax matrix, queue native runs, analyze outputs, inspect maps, and export. | [Read/download PDF](Windows-2.0-Hypercube-Walkthrough.pdf) | [Download Word](Windows-2.0-Hypercube-Walkthrough.docx) |
| Workspaces and Resources | Check Windows resource guidance, back up the complete workspace, open existing workspaces, and move to an SSD. | [Read/download PDF](Windows-2.0-Workspaces-and-Resources.pdf) | [Download Word](Windows-2.0-Workspaces-and-Resources.docx) |
