# Windows 2.0 installation and upgrade

Start with the [installation and upgrade quick-start](Windows-2.0-Installation-and-Upgrade-Quick-Start.pdf) if you are installing Workbench 2.0 or coming from an older R or VisionEval setup. It explains when Workbench reuses R 4.5, when it installs R 4.5.3, and how to preserve an earlier runtime.

For complete setup, asset, workflow, and troubleshooting guidance, use the [Windows 2.0 User Guide](../../../windows/docs/user/VisionEval-Workbench-2.0-Windows-User-Guide.pdf). The [Windows Resources website](https://sites.google.com/view/ve-workbench/documentation/windows-resources) lists both documents.
