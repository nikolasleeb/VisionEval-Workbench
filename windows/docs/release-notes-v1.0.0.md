# VisionEval Workbench 1.0.0 for Windows

This is the independently maintained Windows 11 x64 application. It connects to an existing native VisionEval runtime and does not install, replace, or modify that runtime.

Download `VisionEval-Workbench-v1.0.0-windows-x64-setup.exe` from the GitHub release. Create or select a Workbench workspace, then use **Settings → Runtime** to select and verify `VE_Runtime`, `VE_HOME`, and `Rscript.exe`.

Optional PlanRVA and Virginia MPO packages are installed from their ZIP files through **Settings → Assets**.
