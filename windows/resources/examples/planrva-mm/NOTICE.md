# PlanRVA MM example data notice

This bundled example contains the public PlanRVA VisionEval multimodal model and 52 scenario-input files: 51 CSV files plus `model_parameters.json`. It is included so VisionEval Workbench can be evaluated without first locating a separate model and InputLibrary.

The PlanRVA planning data is distinct from the VisionEval software. It is not owned, endorsed, or published by the VisionEval project. The example is provided as-is, without warranty, and should be reviewed before it is used for policy or investment decisions.

The compatible container is built from the official VisionEval `VE-40-RC6` source and includes the unofficial VisionEval Workbench patch `2026-08-03-composite-household-id-alignment`. See the repository `NOTICE` for complete runtime provenance.
