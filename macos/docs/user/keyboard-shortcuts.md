# Windows Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| Ctrl+N | New Scenario |
| Ctrl+Shift+N | New File |
| Ctrl+Alt+B | Batch Change |
| Ctrl+S | Save Direct Edits |
| Ctrl+Shift+R | Review / Run Selected; always opens confirmation |
| Ctrl+. | Stop Selected Run |
| Ctrl+1 | Explore |
| Ctrl+2 | Create |
| Ctrl+3 | Run |
| Ctrl+4 | Compare |
| Ctrl+R | Refresh |
| Ctrl+, | Settings |

Commands that do not apply to the current project, file, or job are disabled. Ctrl+S saves only unsaved direct table edits; calculated operations use **Apply and Save Change** and notes autosave independently.

Comparison labels, legends, and tooltips communicate direction without relying only on color: `▲ +` means increase, `▼ −` means decrease, and `•` means neutral. Solid elevated borders identify increases and dashed elevated borders identify decreases.
