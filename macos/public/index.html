Runtime Setup Guide

  1. Choose VE_RUNTIMESelect the working folder used to launch VisionEval, usually the folder containing .Renviron, .Rprofile, and models.
  2. Review detected pathsWorkbench reads VE_HOME from .Renviron and finds the matching Rscript from the launch script, r.version, or standard R installations. Advanced overrides remain available.
  3. Verify the connectionSelect Verify runtime. Workbench starts the installed VisionEval version and checks its registered modules. It does not compare hashes or contact GitHub.

Prepared models, logs, and results remain in the Workbench workspace.

  1. Install and start Docker DesktopDocker Desktop is required only for model runs and uncached R data.
  2. Select Install runtimeWorkbench pulls the immutable Apple Silicon image, creates the local alias, and performs the complete verification automatically.
  3. Run modelsAfter verification, Workbench creates temporary containers only while jobs are running.
