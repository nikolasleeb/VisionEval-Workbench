# Tutorials and Walkthroughs

Use the installation guide that matches your computer, then complete the scenario walkthrough for a full **Create → Run → Compare** exercise. PDFs are ready for reading and printing; DOCX files are editable source copies.

> [!IMPORTANT]
> Apple Silicon and Intel Macs use different installers and runtime images. Check **Apple menu → About This Mac** before choosing a guide.
