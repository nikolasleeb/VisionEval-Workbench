# Using Workbench on Windows

## Explore

Inspect input files, descriptions, units, declared dependencies, and available regional data without changing the source folders.

## Create

Create a project from an installed model template and InputLibrary. Preserve an untouched baseline, add scenarios, edit CSV values, and review the saved differences before running.

## Run

Workbench prepares a fresh model copy, applies the scenario overlay, and executes it through the verified native runtime. Entering the Run page never starts a job automatically.

## Compare

Register completed VisionEval datastores and compare tables, statistics, charts, 2D maps, optional 3D geography, and exports. Generated caches can be rebuilt and are not the authoritative result.

Regional ZIP files are installed through **Settings → Assets**. See [Regional Packages](Regional-Packages).
