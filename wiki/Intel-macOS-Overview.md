# Intel macOS Overview

The Intel edition supports Intel Macs running macOS 12 or newer. It uses the same product name, bundle identifier, workspace format, and Explore → Create → Run → Compare workflow as the Apple Silicon edition.

Docker Desktop supplies the isolated AMD64 VisionEval runtime used for model runs and uncached R datastore access. Containers are temporary and are created only when required. The desktop shell and bundled Python backend are native x86_64 binaries.
