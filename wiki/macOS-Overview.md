# Apple Silicon macOS 2.0

Workbench 2.0 supports Apple Silicon Macs running macOS 12 or newer. The Developer ID signed and notarized app uses Docker Desktop and the verified ARM64 VisionEval VE-40-RC7 runtime.

Start with [Mac 2.0 Guides and Walkthroughs](Tutorials-and-Walkthroughs) and the accompanying [Mac videos](https://sites.google.com/view/ve-workbench/documentation/mac-resources).

- [Installation and Runtime](macOS-Installation-and-Runtime)
- [Using Workbench](Using-Workbench-on-macOS)
- [Hypercube](macOS-Hypercube)
- [Workspaces and Resources](macOS-Workspaces-and-Resources)

Version 2.0 has no Intel Mac installer. Earlier Intel editions and instructions remain available through [Intel overview](Intel-macOS-Overview) and [past releases](https://github.com/nikolasleeb/VisionEval-Workbench/releases).
